# Independent machine specifications

`mcc/protocol_292.json` and the MCS `protocol.json`/`evidence.json`/`compatibility.json` retain independent original research data. They are not merged into a fictitious common wire format.

The MCS compatibility register describes the earlier separate 0.2.0 toolkit and its recorded environment. It is retained as historical data; it does not set the unified package version, dependency versions or current test claims. Current product version is 0.1.0; see [current evidence](../docs/evidence.md) and [validation](../docs/tests.md).

Class/method/hash provenance remains build-specific. Neither protocol specification contains physical hardware verification. The [protocol guide](../docs/protocols.md) compares fields and limitations.
