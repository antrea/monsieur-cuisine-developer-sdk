## Analysis tools and target libraries

The public toolkit runs on a separately supplied Python 3.11+ interpreter. Python's official [history and license page](https://docs.python.org/3/license.html) identifies the PSF License Version 2 and additional incorporated-software notices. Python itself is not bundled with this source release. Optional package installation uses setuptools as its build backend (`setuptools>=77`); its upstream [LICENSE](https://github.com/pypa/setuptools/blob/main/LICENSE) contains the MIT permission terms. Setuptools is not a toolkit runtime dependency and is not bundled. These observations identify the external interpreter/build tools rather than relicensing their distributions under this project's MIT license.

The earlier private research used JADX/JADX headless MCP, Apktool/Smali, AAPT, apksigner, pyelftools and Capstone alongside REA. Their executables, libraries, caches, outputs and licenses are not bundled into this release. Tool names document the method; they are not runtime dependencies or endorsements. Exact relevant provider versions and a recorded headless JAR hash are in [research methodology](research/research-methodology.md).

The launcher contains third-party Android libraries such as greenDAO, Gson, OkHttp, Retrofit, RxJava, Picasso, ButterKnife and barcode libraries. Their presence is a fact about the studied application. The public Python toolkit neither ships nor depends on them. It does not attempt to relicense the APK or any extracted library/content under this project's license.

The source distribution includes the **unmodified official Gradle 8.13 wrapper** scripts and wrapper JAR. Upstream copyright/license headers remain in the scripts; its [LICENSE](../../../android/README.md) and [NOTICE](../../../android/README.md) are retained. Gradle uses Apache License 2.0 with incorporated-component notices. The wrapper JAR SHA256 is `81a82aaea5abcc8ff68b3dfcb58b3c3c429378efd98e7433460610fecd7ae45f`; the Gradle binary distribution checksum pinned in wrapper properties is `20f1b1176237254a6fc204d8434196fa11a4cfb387567519c61556e8710aed78`. Optional Android/JVM builds resolve Kotlin 2.3.21, Android Gradle Plugin 8.13.2, JUnit 4.13.2 and its test dependencies externally. Kotlin's [license](https://github.com/JetBrains/kotlin/blob/v2.3.21/license/LICENSE.txt) is Apache 2.0; JUnit's [license](https://github.com/junit-team/junit4/blob/r4.13.2/LICENSE-junit.txt) is EPL 1.0 and Hamcrest 1.3's [license](https://github.com/hamcrest/JavaHamcrest/blob/hamcrest-java-1.3/LICENSE.txt) is BSD. Their external terms remain applicable when developers obtain/build them. No Android dependency is required for the Python runtime.
