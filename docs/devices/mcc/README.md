## Retained limits

MCC target RPM points and acceleration/heating rates are illustrative. The model does not invent an MCU watchdog or autonomous lid/error interlock. Its observed wire scale-state fallback differs from a toolkit `not_available` view and preserves both. RX offset 24 remains physically unidentified. Calibration ENTER/START is documented/decoded and not generated by the public encoder.

The common adapter fixes analyzer reset boundaries, clears delayed RX at legacy client boundaries, harmonizes recorder/replay budgets and bounds native diagnostics. The [migration guide](../../migration.md) distinguishes those corrections from untouched build facts.
