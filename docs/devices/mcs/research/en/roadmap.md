# Roadmap

Completed locally: independent codec/typed SDK, portable fixtures, deterministic virtual board/clock, response faults, recording/replay, declarative scenarios, native desktop and offline tools. This is experimental0.2.0; the scope remains the historical APK.

Next validation: execute the configured multi-platform CI after an owner chooses to publish; collect GUI accessibility/display feedback; compare a lawful additional APK with explicit versioned profiles. Improve model calibration only from authenticated measurements with units and provenance. Generic recipe adapters need a neutral schema and redistributable examples. More registered packet families can gain typed parsers when their layouts are documented independently.

Unresolved research: identify the PowerBoard MCU and original image, actual physical RPM mapping, UART electrical details, bootloader, firmware CRC/packetKey/retry/final verification and safety interlocks. These are evidence gaps, not coding TODOs that can be filled by guessing. A real transport/flasher is outside this release and is not planned implicitly. No remote repository or publication has been performed.


Integrated Android Connection and the original Kotlin SDK/developer APK are now implemented. See [Android Connection](../android-connection.md) and the [0.2.0 validation audit](../../../../evidence.md).
